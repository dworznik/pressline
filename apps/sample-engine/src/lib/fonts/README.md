# Bundled font

`AtkinsonHyperlegible-Bold.ttf` — Atkinson Hyperlegible by the Braille Institute of America, Inc., licensed under the SIL Open Font License 1.1 (`OFL.txt`). Fetched from the Google Fonts repository (`ofl/atkinsonhyperlegible`).

The template converts text to outlines with this face, so the rendered Printfile needs no font on the host: Vercel functions and Cloudflare Workers ship none, and `<text>` would come out as boxes.
